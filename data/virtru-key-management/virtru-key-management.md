## Overview

Virtru key management system software provides security solutions to enterprises and small businesses, centered on end-to-end encryption and access controls for email and file data.

## Features

- Granular access controls
- Persistent file protection
- Outlook integration
- Gmail integration
- Forwarding prevention
- Microsoft 365 integration
- Secure collaboration
- End to end encryption
- Encryption
- Database security
- Asset tracking
- Check-in/check-out
- Master key management
