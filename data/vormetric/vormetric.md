## Overview

Vormetric is a data security and encryption platform originally developed by Vormetric, now part of Thales following its acquisition. It provides data-at-rest encryption, tokenization, and access controls to protect sensitive information across databases, file systems, big data platforms, and cloud environments.

## Key Features

- Database encryption
- Transparent data encryption
- High availability
- Audit logging
- Policy management
- Data masking
- Cloud security
- Access control
- Tokenization
- Key management

## Deployment

Vormetric supports deployment on-premises and in cloud environments, integrated with Thales key management and CipherTrust Data Security Platform capabilities.
