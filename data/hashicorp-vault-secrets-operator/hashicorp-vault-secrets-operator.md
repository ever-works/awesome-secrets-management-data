## Overview

HashiCorp Vault Secrets Operator is the official Kubernetes operator for synchronizing secrets from HashiCorp Vault into Kubernetes Secrets. It enables Vault-standardized teams to manage secrets in Vault and have them automatically injected into Kubernetes workloads as native Kubernetes Secrets.

## Features

- Synchronizes secrets from HashiCorp Vault to Kubernetes Secrets
- Official operator for HashiCorp Vault in Kubernetes environments
- Supports static and dynamic secrets from Vault
- Kubernetes-native secret distribution
- Designed for teams already standardized on HashiCorp Vault

## Deployment

Self-hosted, Kubernetes-native operator.
